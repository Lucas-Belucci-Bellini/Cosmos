# Roadmap

| Fase | Objetivo | Saída |
|---|---|---|
| Phase 0 — Discovery | entender Baluarte, Cosmos e NEXORA | inventários, matriz, catálogo e decisões |
| Phase 1 — Foundation | criar base técnica limpa | workspace, CI, schemas, testes e observabilidade |
| Phase 2 — Core | contratos e runtime | shell, router, storage, errors e loaders |
| Phase 3 — Application | reconstruir módulos prioritários | V7, Arsenal, Knowledge selecionado |
| Phase 4 — Integrations | serviços aprovados | adapters, APIs, auth e storage externo |
| Phase 5 — Optimization | reduzir custo e peso | cache, lazy data, benchmarks e deduplicação |
| Phase 6 — Production | operação segura | deploy, backup, monitoramento e recuperação |
| Phase 7 — Future | módulos adiados | mobile, desktop, IA avançada e datasets grandes |

A implementação fica bloqueada em novos módulos até a Phase 0 possuir checklist suficiente e uma ADR aprovar a fundação.
