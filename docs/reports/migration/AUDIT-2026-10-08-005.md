# Relatório de auditoria — AUDIT-2026-10-08-005

## Objetivo

Registrar a decisão SQL-first do Cosmos e as evidências de banco de dados localizadas na documentação do Projeto-Baluarte. Esta rodada é arquitetural/documental; não criou nem aplicou schema em nenhum banco.

## Evidências consultadas na origem

1. `docs/TAXFORGE-SUPABASE-SCHEMA-RECONCILIATION.md`
2. `docs/SUPABASE-TAXFORGE-RECONCILIATION.md`

Os documentos descrevem especificamente o domínio TaxForge, não necessariamente todos os módulos do Baluarte.

### Divergência registrada na documentação TaxForge

- O caminho de aplicação documentado usa Drizzle orientado a MySQL/TiDB em parte do repositório.
- O projeto Supabase descrito contém 23 tabelas PostgreSQL com prefixo `taxforge_`.
- Os documentos dizem que os modelos ainda não são equivalentes e que o banco Supabase não deve ser considerado canônico apenas por existir.
- A documentação exige revisão das políticas RLS e funções expostas antes de expansão em produção.
- Logo, não é seguro copiar essas tabelas para o Cosmos nem assumir que esse projeto Supabase deve hospedar o Cosmos.

## Decisão registrada no Cosmos

O Cosmos passa a ter direção **SQL-first**, com PostgreSQL como alvo central do modelo relacional. A escolha do provedor gerenciado continua em avaliação. SQLite pode ser considerado para uso local/offline futuro, desde que tenha fronteira e sincronização explícitas.

## Regras de segurança e implementação

- A UI não recebe credenciais privilegiadas nem conecta diretamente ao banco.
- Rust e Python usam contratos autorizados; não criam caminhos paralelos para contornar regras de domínio.
- Queries são parametrizadas; schema evolui por migrações versionadas.
- Segredos, tokens e sessões do Baluarte não são migrados.
- Dados estruturados e relacionais ficam no SQL; arquivos grandes permanecem em object storage/CDN quando apropriado.
- Se Supabase for escolhido, RLS deve ser revisado por tabela/operação e as funções expostas devem ter privilégios avaliados.
- Nenhuma tabela é criada apenas porque um módulo foi inventariado; primeiro confirmar consumidor e fluxo.
- Nenhum teste de banco foi executado nesta rodada, e nenhum banco remoto foi alterado.
